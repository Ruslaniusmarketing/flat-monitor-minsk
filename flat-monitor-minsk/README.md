# Мониторинг аренды квартир в Минске → Telegram

Раз в 10 минут бот проверяет Kufar, Onliner, Realt, Domovita (и другие площадки, если включить),
отсеивает неподходящее, ставит рейтинг и присылает карточки в Telegram.

**Первый запуск** разбирает всё, что сейчас опубликовано (до 15 страниц Kufar/Onliner, до 8 — Realt/Domovita):
присылает все подходящие варианты карточками — сначала свежие, потом старые. Длится 20–40 минут.
Дальше бот смотрит только свежие страницы и пишет о новых объявлениях.

## Что отсеивается
- дороже $550 (и дешевле $150 — обычно посуточно или комната);
- не 1–2 комнаты, студии, посуточная аренда, подселение;
- агентства и риелторы: по пометке площадки (компания/агент) и по тексту — «агентство», «риелтор», «комиссия» и т.п. («без комиссии» и «без посредников» не мешают). Выключается `filters.exclude_agencies: false`;
- Заводской и Партизанский районы (по району в объявлении и по координатам через OpenStreetMap);
- площадь вне 35–62 м².

## Свежие и старые
Каждая карточка помечена: «🆕 Свежее» — опубликовано меньше 3 дней назад, «🕰 Старое · висит N дн.» — дольше.
Свежие идут первыми, старые тоже присылаются. Порог меняется в `config.yaml` → `send.fresh_days`.
На Kufar дата — время последнего поднятия объявления, поэтому поднятое старое объявление может считаться свежим.

## Как считается рейтинг
| Признак | Баллы |
|---|---|
| Петровщина / Малиновка / Михалово / Грушевка / Ин-т культуры | +3 |
| Центр по пр. Победителей / Дрозды | +2 |
| Кирпичный дом | +3 (монолит +1, панель 0, блочный −2) |
| Двуспальная / большая кровать | +2 (только диван −1, без мебели −2) |
| Евродвушка или 2 комнаты | +1 |
| Площадь 35–50 м² | +1 |
| Собственник | +1 |

🔥 — от 7 баллов, ✅ — от 4, 🟡 — ниже (смотреть вручную, обычно в объявлении нет данных).

## Как поменять фильтры
Всё в `config.yaml`: бюджет, комнаты, площадь, районы, баллы, площадки. На GitHub — открыть файл,
нажать карандаш, поправить, Commit. Следующий проход возьмёт новые настройки.

- Слишком много сообщений → `send.min_score: 3` или `only_priority_zones: true`.
- Добавить район → `priority_zones` (ключевые слова и/или точки с координатами).
- Отключить площадку → `enabled: false`.
- Слать и девушке → в секрет `TELEGRAM_CHAT_ID` два id через запятую или id общей группы с ботом.

## Режимы (Actions → flat-monitor → Run workflow)
- `test` — тестовое сообщение в Telegram;
- `dry` — проход без отправки, результат в логе;
- `run` — обычный проход (так же работает расписание).

## Запуск на своём компьютере (если площадки блокируют серверы GitHub)
```
pip install -r requirements.txt
set TELEGRAM_BOT_TOKEN=...        (macOS/Linux: export TELEGRAM_BOT_TOKEN=...)
set TELEGRAM_CHAT_ID=...
python bot.py --mode test
python bot.py --loop 600
```
Компьютер должен быть включён — бот проверяет площадки каждые 10 минут, пока окно открыто.
